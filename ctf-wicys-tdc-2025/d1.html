D1. Mystery Mail

★☆☆☆☆ EASY 100 PTS EXTORTION WiCyS + Target Defense Challenge 2025: BURROWING THE BUSINESS

>_ Identify the malicious IP address in an extortion email.

Challenge

What a way to start your day... you've just logged on as a member of Personalyz.io's Cybersecurity team and see the last thing any cyber professional wants to see: an extortion email at the top of your inbox. Looks like we've received a menacing message from an unknown sender, claiming that sensitive data has been stolen from the company. The email demands a ransom and threatens to release the data if the demand is not met within 48 hours.

Given the nature of the data we process, this is a serious threat to us and our customers.

You've been tasked with performing some analysis on the email itself to ensure our responding teams can respond appropriately.

To start, can you determine the sender's original IP address?

Objectives

Identify the sender's IP address using the attached email file.

Don't overthink it!

Flag Format

The flag will be a valid IP address, for example:

  • 242.229.211.211
  • 243.151.196.173

Solution

Inside the challenge is a file for you to download called extortion_note.eml. This is the file you will need to identify the sender's IP address.

For this challenge, I will be downloading the file to my Kali Linux virtual machine. After downloading the file, I used the following commands in terminal to help organize my folders for this CTF. In the downloads folder, I used the following prompts.

Make a new directory folder:

mkdir D1

Move the file into the new directory:

mv extortion_note.eml D1/

Change to the new directory:

cd D1

Verify the file is in the new directory and review permissions:

ls -l

Next, I used the concatenate command to read the contents of the file:

cat extortion_note.eml

Below is the output:

Terminal output of cat extortion_note.eml  |  Click to enlarge

The objective is Identify the sender's IP address using the attached email file. Focus on the header of the email where we received the email from.

Email header — Received fields showing the routing path  |  Click to enlarge

We can see we have 3 Received sources from the email header. Here we identified the hops or the route the email took to get from source to destination. The order in which the path is listed is in timestamp DESC (descend) order. The path is broken down as follows:

252.44.98.29 >>> 250.24.46.164 >>> 251.14.1.16

Thus, the source of the email has to be coming from IP address 252.44.98.29.

MITRE ATT&CK

In this challenge, we learned how to inspect the headers of an email .eml file to identify the IP origin of the email. The reason why we have multiple received entries is, every time an email passes through a mail server, it appends a received entry to the email along with the timestamp. Thus, if we go with the very first entry, based on the timestamp, we were able to identify the origin IP address.

Tactics

In the MITRE ATT&CK framework, this tactic falls under TA0040 — Impact as the contents of the email imply that data has been exfiltrated and the attacker is extorting the organization for monetary gain.

Techniques

In the MITRE ATT&CK framework, this technique falls under T1657 — Financial Theft, as the adversary is threatening to expose the data publicly if the ransom demands are not paid on time.

Procedures

Shadow Gopher sent an email to the Personalyz.io organization demanding a ransom payment within a time limit or else the adversary will publish sensitive company and PII data.
