P4. Hints

★☆☆☆☆ EASY 100 PTS TUTORIAL WiCyS + Target Defense Challenge 2025: BURROWING THE BUSINESS

>_ Bold letters in the source — Inspect reveals what View Source cannot.

Challenge

Some challenges have hints that you can unlock if you're feeling stuck.

Be warned: they do cost points! The design ensures you'll never go negative, but if you somehow find yourself in this situation, sign up for office hours for assistance.

If you're shooting for the top, use hints sparingly. Even if you're just in it for the challenge, give everything a good try before resorting to hints — it'll be more rewarding and you might retain more if you figure it out yourself.

Objective

Unlock all the hints to find the flag! Note that in this challenge, you must unlock them in order. If you're not prompted to spend points, then you haven't met the unlock requirements of the hint.

  1. View Hint: Unlock this hint first!
  2. View Hint: Unlock this hint second!
  3. View Hint: Unlock this hint last!

Solution

Unlock all of the hints to find the flag. We also gain an understanding of how hints work and the cost for using them (if we choose to use them).

View Hint: Unlock this hint first!

This hint costs 10% of the challenge's value, or 10 points. Unlocking this will make the next hint available for unlock.

View Hint: Unlock this hint second!

This hint costs 20% of the challenge's value, or 20 points. It's also only available if you unlock the first hint. Unlocking this will make the walkthrough available for unlock.

View Hint: Unlock this hint last!

This is the walkthrough of the challenge. It costs 60% of the challenge's value, but is only available after unlocking the first 2 hints.

Altogether, unlocking this hint will cost 90% of the value of the challenge, but you're pretty much guaranteed to get it from this.

The flag is made of all the bold letters in this hint. If you're having trouble seeing the bold letters, copy this text out into a word processor or view as HTML.

Finding the Hint

The best way to find the flag is to use the Inspect tool in your browser window. In Google Chrome, simply highlight a sample of the hint text, right-click inside the browser window, and select the Inspect option.

Viewing the page source will not reveal the text — it will only show the static HTML of the site. To view dynamic changes from JavaScript, use the Inspect option instead.
